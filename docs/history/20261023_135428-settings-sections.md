# 설정: "동작"을 나누고 순서 정리, 고급 설정을 접는 섹션으로

## 왜
"동작" 섹션에 성격이 다른 항목(조작 중 화면 표시, 화면 가리기와 하위 항목, 배터리)이 섞여 있었다.
자동 호스팅 켜기는 그 아래 따로 붙은 카드였고, 고급 설정만 섹션 제목 없이 카드 머리줄이었다.

## 어떻게
- 순서: 언어·테마 → 단축키 → 자동으로 호스팅 켜기 → 다른 기기 조작 중(전환 팝업, 화면 키보드) →
  화면 가리기(가리기, 알림·잠금 해제 시 풀기, 다시 가리기) → 백그라운드 실행(배터리 최적화) → 고급 설정 → 버전.
- "화면"은 아래 "화면 가리기"와 헷갈려 "언어·테마"로 이름을 바꿈. "동작"(`settings_behavior`)은 없앰.
- 자동 호스팅: 카드 안 제목·설명을 섹션 제목·설명으로.
- 고급 설정: 다른 섹션처럼 섹션 제목(설명 포함). 제목 줄을 누르면 접고 펼침(기본 접힘), 펼치면 카드가 나옴.
- 항목 자체와 섹션 안 순서는 그대로. 6개 언어.
