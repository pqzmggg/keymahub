# 고급 설정: 블루투스 전송 수치를 앱에서 조정

- 왜: 마우스 지연이 환경(호스트, 무선, 폰에 붙은 기기)에 따라 달라 코드 상수로는 맞추기 어려움. 사용자가 직접 수치를 찾을 수 있게.
- 어떻게:
  - `core/Tuning.kt`: 항목별 권장값·범위(`Spec`), 범위 밖은 `clamped()`. `UiPrefs.tuning`으로 저장(`tuning_*` 키).
  - 즉시 적용: 송신 코드가 보고마다 `Hub.ui.value.tuning`을 읽음(`HidSender` 이동 간격, `BleHid.pump` 창·확인 대기·재시도·로그 기준). LE 2M과 마우스 즉시 받기는 바뀌면 `Hub.onUiChanged`로 서비스가 바로 다시 요청(`BleHid.setLe2m`, `PointerCaptureOverlay.refreshDispatch`).
  - 설정 화면 맨 아래 '고급 설정'(펼쳐야 보임): 항목마다 이름 옆 `?`(설명 대화상자), 권장값·범위·단위, 숫자 입력(범위 안이면 입력하는 대로 적용, 밖이면 오류 표시만), '권장값으로 되돌리기'. 6개 언어.
  - 권장값(= 기본값):
    - 마우스 이동 보고 간격 10ms(4~50): 짧은 연결 간격(11~15ms)이 나르는 양에 맞춰 스택에 쌓이지 않게. 이전 8ms.
    - 동시 전송 개수 2(1~8): 스택에 넘긴 보고는 합칠 수 없으니 최소한(하나 전송 중, 하나 대기). 이전 3.
    - 전송 확인 대기 250ms(30~1000), 재시도 간격 5ms(1~50), 지연 로그 기준 50ms(10~1000): 이전과 같음.
    - LE 2M PHY 켬, 마우스 즉시 받기 켬(Android 11+): 이전과 같음.
  - 변경 내용은 로그에 남음(`advanced settings: …`).
  - 한계: 권장값은 추정, 실기기 측정 전. Compose UI는 이 환경에서 컴파일 불가(문법·앱 참조만 확인), 최종 빌드는 CI.
