# 화면 가리기 중 잠금을 해제하면 가리기 풀기

전원 버튼을 누르고 잠금을 해제하면 가리기가 풀리길 원함(알림으로 풀기의 후속).

- 전원 버튼은 시스템이 먼저 처리해 앱(접근성 키 필터)에 오지 않는다. 화면 켜짐 신호는 조작 중인 마우스·키 입력으로도 와서 구분이 안 된다.
- 대신 `ACTION_USER_PRESENT`(잠금 해제)를 받으면 터치처럼 가리기를 걷는다. 지문은 가리기 아래에서도 인식된다.
- 화면 잠금이 보안 잠금(PIN·패턴·비밀번호, `isDeviceSecure`)일 때만: 잠금 "없음"이면 화면이 켜질 때마다(마우스 클릭으로도) 이 신호가 오기 때문.
- 설정: "잠금을 해제하면 가리기 풀기"(기본 켬).
- 한계: Smart Lock(신뢰할 수 있는 기기·장소)으로 인증 없이 풀리는 상태에서는 마우스 클릭으로 화면이 켜졌을 때도 풀릴 수 있다. 그럴 땐 이 설정을 끈다.
