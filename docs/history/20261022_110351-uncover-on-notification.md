# 화면 가리기 중 알림이 오면 가리기 풀기

## 왜
가리기(접근성 오버레이)는 상태 표시줄·알림 팝업·잠금 화면보다 위에 있어서, 다른 기기를 조작하는 동안 폰에 온 알림이 보이지 않았다.
시스템 알림을 가리기 위로 올릴 방법은 없다(창 순서는 앱이 못 바꿈).

## 어떻게
- 가리기가 켜진 채로 대상 기기를 조작하는 동안만 접근성 서비스가 `TYPE_NOTIFICATION_STATE_CHANGED`를 구독한다(평소엔 구독하지 않음, 새 권한 없음).
- 알림 이벤트가 오면 터치와 똑같이 가리기를 걷는다: "터치가 없으면 다시 가리기"가 켜져 있으면 그 시간 뒤 다시 가리고, 꺼져 있으면 다음에 다른 기기로 전환할 때 다시 가린다.
- 걸러내기: `Notification`이 없는 이벤트(토스트), 이 앱의 알림(상태 알림). 무음·낮은 중요도 알림은 시스템이 이벤트를 보내지 않는다.
- 설정: 고급이 아닌 일반 설정의 가리기 아래 "알림이 오면 가리기 풀기"(기본 켬).
