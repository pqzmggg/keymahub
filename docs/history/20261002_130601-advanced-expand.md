# 고급 설정: 스위치 대신 펼치기 화살표, ? 아이콘 통일

- 왜: 고급 설정을 여는 스위치가 '고급 설정을 적용할지' 정하는 설정처럼 보였음. 항목의 ? 버튼이 프로필 자동 활성화의 ?(동그라미)와 모양이 달랐음.
- 어떻게:
  - 카드 머리(제목 '고급 설정' + 설명)를 누르면 펼치고 접음. 오른쪽에 꺾쇠 화살표(접힘 ˅, 펼침 ˄). 위의 섹션 제목은 머리와 겹쳐 뺌. 쓰지 않게 된 `advanced_show` 문자열 삭제.
  - 동그라미 ? 버튼을 `HelpButton`(Common.kt)으로 공용화해 홈의 활성화 방식 도움말과 고급 설정 항목이 함께 씀. 화면 읽기용 설명 '도움말' 추가.
