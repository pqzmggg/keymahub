# 마우스 뒤로·앞으로 버튼을 대상으로 전달

- 왜: 안드로이드는 마우스의 뒤로·앞으로 버튼을 버튼 상태와 함께 BACK / FORWARD 키로도 보냄. 키 처리(`A11yCapture.onKeyEvent`)는 키보드의 키만 넘기고 마우스의 키는 이 기기에 돌려보내서, 대상을 조작하는 중에 폰에서 뒤로가기가 실행되거나(버튼 상태에 4·5번이 없는 기기에서는) 대상에 전달되지 않을 수 있었음.
- 어떻게:
  - 마우스(SOURCE_MOUSE)에서 온 BACK / FORWARD 키를 라우터에 버튼 4·5로 넘김. 키처럼 누름이 간 곳으로 뗌도 감: 폰에서 누른 건 폰에서 떼고, 대상에서는 대상 버튼으로.
  - 버튼 상태로도 같은 버튼이 들어오면 라우터가 두 번째 누름과 짝 없는 뗌을 무시해 한 번만 눌림(테스트 추가).
  - 대상을 조작하는 중 마우스에서 보내지 못한 키는 로그에 남김(`key left to this device (mouse …)`): 특수 버튼이 안드로이드에 어떤 이벤트로 오는지 확인용.
  - 한계: 로지텍 제스처·휠 모드 버튼처럼 제조사 전용 프로토콜(HID++)로 동작하는 버튼은 안드로이드에 표준 이벤트로 오지 않아 전달할 수 없음.
