# 고급 설정: 공통·마우스·키보드로 나누고 키보드 우선 전송 추가

- 왜: 키보드와 마우스는 대상별 대기열(`ReportQueue`)과 동시 전송 개수(창)를 함께 써서, 키가 앞서 쌓인 마우스 보고 뒤에서 기다림. 동시 전송을 3 → 2로 줄인 뒤 타자 지연이 늘어난 느낌.
- 어떻게:
  - 키 우선 전송(기본 켬): 키보드·미디어 키 보고가 대기열 끝에 기다리는 마우스 이동 앞으로 감. 클릭(버튼 변화) 앞으로는 가지 않음: 클릭 후 타자 순서가 바뀌면 엉뚱한 곳에 입력됨(테스트 추가).
  - 키 전용 추가 전송 개수(기본 1, 0~4): 마우스가 창을 채워도 키는 그만큼 더 보낼 수 있음. 0이면 이전처럼 키도 기다림.
  - 화면: 공통(동시 전송·확인 대기·재시도·지연 로그·LE 2M), 마우스(이동 간격·즉시 받기), 키보드(우선 전송·추가 전송). 6개 언어.
