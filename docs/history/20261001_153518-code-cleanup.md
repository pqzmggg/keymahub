# 코드 정리: 경쟁 조건·버그 수정, 중복·미사용 코드 제거, 구조 분리

- 왜: 전체 코드 검토(클린 코드, 중복, 지나친 복잡도, 미사용 코드, 구조). 그 과정에서 실제 버그도 발견.
- 버그 수정:
  - 서비스 시작 중 중지하면 정리가 빠지거나 '호스팅 중'으로 남을 수 있었음 → 시작 후반을 onDestroy와 같은 메인 스레드에서.
  - 접근성 serviceInfo를 두 스레드가 동시에 고쳐 한쪽 변경이 사라질 수 있었음 → 한 번에 하나씩(editServiceInfo).
  - BLE: 같은 링크에 hold가 둘 생길 수 있음(join), 대상 선택과 끊김이 겹치면 선택이 사라짐(active), 끊긴 링크로 보낸 입력이 재연결 때 나감, BT가 꺼지면 페어링 모드가 켜진 채 남음, 만들던 광고 세트가 BT 꺼진 뒤 살아남음.
  - 기본 프로필(이름 없음)이 바로가기·Tasker·토스트에서 빈 이름으로 보였음 → '기본'.
  - 대상 전환 때 이전 대상의 소수점 이동량이 넘어감, 페어링 남은 시간이 첫 프레임에 0:00.
- 정리:
  - BLE 대상별 전송 상태 5개 맵 → `Outbox` 하나. GATT 데이터베이스 → `HidGattDatabase.kt`.
  - 오버레이 창 설정·제거·dp(`capture/Overlays.kt`), 환경설정 파일(`keymaPrefs`)·키 상수, 앱 버전, 보조키 이름, 프로필 슬롯 변환, 라우터 출력 분기, 안내 카드·드래그 손잡이·대체 프로필 판정 공용화.
  - 테마·설정 단계 상태를 MainActivity 밖으로(`Theme.kt`, `SetupScreen.kt`).
  - 미사용 코드 제거(`ReportQueue.clear` 등), 안에서만 쓰는 것은 private으로.
  - 키보드·마우스 보고서 단위 테스트 추가.
- 검증: 이 환경은 Google Maven이 막혀 Gradle 빌드 불가. Maven Central의 Kotlin 컴파일러와 Robolectric android-all로 UI 밖 코드를 컴파일하고 단위 테스트 55개 통과. Compose UI는 문법·앱 내부 참조만 확인, 최종 빌드는 CI.
- 하지 않은 것: Rust LAN PoC(`core/`, `poc/`)는 지금 앱이 쓰지 않지만 P0 기록이라 그대로 둠. UI 체크박스 행·닫기 대화상자 공용화와 화면 이동 분리는 컴파일 없이 하기엔 위험해 보류.
