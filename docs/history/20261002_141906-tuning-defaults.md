# 고급 설정 기본값을 실사용에서 찾은 값으로

- 왜: 고급 설정으로 직접 찾은 값(태블릿 + 자체 블루투스 마우스 → Windows PC)이 가장 잘 맞음.
- 어떻게:
  - 기본값(= 권장값): 이동 간격 10ms, 동시 전송 2, 확인 대기 150ms(이전 250), 재시도 10ms(이전 5), 지연 로그 70ms(이전 50), LE 2M 켬, 마우스 즉시 받기 끔(이전 켬).
  - 켬/끔 항목도 항목별 권장값을 표시(`권장: 켬` / `권장: 끔`).
  - 저장은 기본값과 다른 값만: 바꾸지 않은 항목은 앞으로 기본값이 바뀌면 따라감. 이전 빌드에서 이미 저장된 값은 그대로라, 기존 설치는 '권장값으로 되돌리기'를 한 번 눌러야 새 기본값이 됨.
