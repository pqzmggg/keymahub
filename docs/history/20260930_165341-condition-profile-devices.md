# 활성화 조건: 프로필에 넣은 기기만

- 왜: 조건 목록에 페어링된 모든 기기가 나와서, 프로필에 없는(그 프로필로는 전환할 수 없는) 기기를 조건으로 걸 수 있었음. 프로필에서 기기를 빼도 조건에는 남았음.
- 어떻게:
  - 조건 목록 = 이 프로필의 기기(단축키 순서). 없으면 "먼저 기기를 추가하세요" 안내.
  - 프로필에서 기기를 빼면(−) 조건에서도 빠짐 (`closeGap`).
  - `setWhenConnected`는 프로필 기기만 받음. 저장된 설정을 읽을 때 프로필 밖 기기 조건은 정리.
  - '규칙 기반 자동'은 유지: 일부 기기만 조건으로 고를 수 있고 목록 순서가 우선순위라 '완전 자동'과 다름.
