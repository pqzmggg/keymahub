# 튜토리얼: 프로필 자동 활성화 페이지 추가

- 왜: 프로필이 저절로 바뀌는 방식과 갤럭시 루틴으로 바꾸는 방법이 튜토리얼에 없었음.
- 어떻게: 3쪽(프로필)과 단축키 쪽 사이에 4쪽 추가 (전체 5쪽).
  - 메인 화면 '프로필 자동 활성화'에서 고르는 세 방식(완전 자동·규칙 기반 자동·끄기)을 앱의 도움말과 같은 문구(`MODES`)로 보여줌.
  - 팁: 갤럭시 모드 및 루틴에서 KeymaHub의 '(프로필) 활성화' 바로가기로도 바꿀 수 있고, 이때는 앱이 루틴이 고른 프로필을 바꾸지 않도록 앱의 자동 활성화를 끄는 것을 권장.
  - `TUTORIAL_VERSION` 4 → 한 번 다시 보임. 6개 언어.
