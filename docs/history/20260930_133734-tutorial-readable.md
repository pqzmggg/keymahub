# 튜토리얼: 줄글 대신 한 줄 요약 + 번호 단계 + 팁 카드

- 왜: 쪽마다 긴 문단이라 눈에 잘 안 들어옴. Windows에서 이 기기가 블루투스 목록에 안 보이면 '모든 장치 표시'를 눌러야 하는데 안내가 없었음.
- 어떻게: 각 쪽 = 제목 + 한 줄 요약 + 번호 붙은 짧은 단계 + (필요하면) 팁 카드.
  - PC·태블릿 추가 쪽 팁: "Windows: 목록에 없으면 '모든 장치 표시'" + Windows '디바이스 추가' 창 캡처(`drawable-nodpi/tutorial_windows_show_all.png`, 한국어 Windows 화면).
  - 단축키 쪽: 문장 대신 키 모양 칩(`Alt + Shift + 1` → 이 기기).
  - `TUTORIAL_VERSION` 3 → 한 번 다시 보임. 6개 언어.
