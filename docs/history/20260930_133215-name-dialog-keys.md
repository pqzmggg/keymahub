# 입력 대화상자: Enter로 확인, Esc로 취소

- 왜: 새 프로필·프로필 이름·기기 이름, 프로필 기기 추가를 키보드로 하면서도 저장/추가/취소 버튼을 눌러야 했음.
- 어떻게 (`NameDialog`): 열리면 입력란에 바로 포커스. 물리 키보드 Enter(숫자패드 Enter 포함) → 저장 버튼과 같음(비어 있으면 무시), Esc → 취소. 화면 키보드의 완료 키도 저장.
- 프로필 기기 추가 (`AddDeviceDialog`): Enter → 추가(고른 기기가 없으면 무시, 추가할 기기가 없으면 닫기), Esc → 취소. 체크는 방향키로 옮겨 Space로.
