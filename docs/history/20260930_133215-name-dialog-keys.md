# 대화상자: Enter로 확인, Esc로 취소 (모든 팝업 공통)

- 왜: 새 프로필·이름 바꾸기·기기 추가 등 팝업을 키보드로 쓰면서도 저장/추가/취소 버튼을 눌러야 했음. 팝업마다 동작도 제각각.
- 어떻게: 공통 `Modifier.dialogKeys(onEnter, onEscape)`(Common.kt) — 팝업이 열리면 내용에 포커스, **Enter = 주 버튼**, **Esc = 취소·닫기**. 모든 팝업에 적용:
  - 이름 입력(새 프로필, 프로필·기기 이름 바꾸기): 입력란에 바로 포커스, Enter = 저장(비어 있으면 무시). 화면 키보드 완료 키도 저장.
  - 프로필 기기 추가: Enter = 추가(고른 게 없으면 무시, 추가할 기기가 없으면 닫기).
  - 확인 대화상자(삭제 등): Enter = 확인 버튼.
  - 접근성 안내(설정 단계): Enter = 동의.
  - 자동 선택 방식 도움말: Enter·Esc = 닫기.
  - 언어 선택: Enter는 포커스된 항목 선택(방향키로 이동), Esc = 닫기.
  - 진단 로그: 메모 입력란에서 Enter = 메모 추가, Esc = 닫기(복사는 버튼으로만).
