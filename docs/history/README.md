# 진행 기록

변경(PR) 하나마다 파일 하나: `NNNN-YYYY-MM-DD-HHMM-짧은-이름.md`
(예: `0095-2026-10-01-1430-bt-off-notice.md`).

- `NNNN`: PR 번호, 4자리(앞을 0으로 채움). PR마다 다르고 계속 커지므로 이름순 정렬이 곧 순서다
  (PR을 연 순서; 같은 분에 만든 PR끼리도 섞이지 않음). PR을 연 뒤 번호를 알고 나서 파일을 만든다.
- 날짜·시각: 한국 시간(KST) 24시간제.
한 파일에 쌓으면 동시에 열린 PR끼리 같은 자리에서 충돌하므로 나눈다.

파일 내용은 짧게:

- 제목 한 줄 (무엇을 바꿨나)
- 왜 (문제·발견)
- 어떻게 (결정, 고른 방법과 그 이유, 한계)
