# 진행 기록

변경(PR) 하나마다 파일 하나: `yyyyMMdd_HHmmss-짧은-이름.md`
(예: `20261001_143015-bt-off-notice.md`).

- 날짜·시각: 파일을 만든 한국 시간(KST), 24시간제(00~23시), 초까지. 이름순 정렬이 곧 시간순이다.

한 파일에 쌓으면 동시에 열린 PR끼리 같은 자리에서 충돌하므로 나눈다.

파일 내용은 짧게:

- 제목 한 줄 (무엇을 바꿨나)
- 왜 (문제·발견)
- 어떻게 (결정, 고른 방법과 그 이유, 한계)
