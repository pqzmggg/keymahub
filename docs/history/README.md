# 진행 기록

변경(PR) 하나마다 파일 하나: `YYYY-MM-DD-HHMM-짧은-이름.md`, 시각은 한국 시간(KST) 24시간제 (예: `2026-10-01-1430-bt-off-notice.md`).
이름순으로 정렬하면 시간순이 된다.
한 파일에 쌓으면 동시에 열린 PR끼리 같은 자리에서 충돌하므로 나눈다.

파일 내용은 짧게:

- 제목 한 줄 (무엇을 바꿨나)
- 왜 (문제·발견)
- 어떻게 (결정, 고른 방법과 그 이유, 한계)
